# Maktaba Releases

ملفات التثبيت والتحديثات العامة لتطبيق **مكتبتي** على Windows x64.

تُنشر ملفات Installer المعتمدة والموقعة في [Releases](https://github.com/Elsayed-Gamal/maktaba-releases/releases). تشغيل التطبيق يحتاج ترخيصًا صالحًا للجهاز، واستحقاق التحديثات يتحدد حسب الترخيص.

هذا المستودع مخصص لملفات التوزيع العامة وتوثيق تنزيلها. لا يحتوي كود التطبيق أوبيانات المكتبات أوحسابات الموظفين أومفاتيح التوقيع الخاصة.
